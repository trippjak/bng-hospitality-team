# BNG Perplexity Project setup

## Shared sources and variables

Add the GitHub connector using the BNG-authorized account. Select the verified platform repository. The procedures and supporting files ship in this ZIP. Point each member at its entry skills and specify the trigger. Explicitly assign mandatory gates by name even if the runtime can auto-select skills. Reading a procedure is sufficient for planning. Executing it requires its actual tools, dependencies, model seat where prescribed, and evidence.

| Member | Skill or definition to open | Additional capability or task input |
|---|---|---|
| Project Host | session-open on resume, ux-ui-studio for a Studio run, section-close or team-meeting at their milestones | Repo and project files, isolated browser runner for full Studio verification, revision and evidence directory |
| 4D Remediation | ratchet-review for a named structural target | Writable task checkout, project test/build runtime, measurement scripts, target and proof command |
| Blind Code Reviewer | blind-code-review and bounded-qa for a ratchet batch, Matt Pocock code-review for an ordinary diff | Fresh review context, read-only Stage A packet, then Stage B source and rationale |
| UI Design Lead | ux-ui-team and ux-ui-studio for substantial UI work | Authorized lead seat, brand sources, Figma only for a Figma deliverable |
| 5D UI Ratchet Lead | ui-ratchet for triage and repair | Astra seat, Node and measurement scripts, revision-matched evidence, writable checkout for authorized repair |
| Visual Craft Gate | Studio no-vibe-code agent definition | Fresh multimodal reviewer, brand brief, shared evidence packet |
| UX/UI QA Gate | Studio ux-ui-qa agent definition | Fresh multimodal reviewer, exercised states and shared packet, isolated browser for standalone collection |
| UX Copywriter | Studio ux-copywriter and its copy guidelines | Screen/state, verified terminology, approved copy source |
| Domain & Evidence | Matt Pocock domain-modeling, research for sourcing, grilling for an unresolved owner decision, fact-checker for external claims | Basic Memory reads, approved policy sources, steward writes on approval |
| Architecture & Delivery | Matt Pocock diagnosing-bugs, tdd, codebase-design, or prototype according to task | Task checkout, normal entry point, reproducible test runner |
| Brand & Visual | ux-ui-team material-selection and reference-discovery guidance, brand-design-audit when auditing | BNG asset library, design connector when the assignment uses it |
| Interaction | ux-ui-team UX evidence workflow and UI checklist | Relevant domain relations, journey and state evidence |
| Frontend | ux-ui-team 4D execution reference and ui-ratchet | Task checkout, build and test tools, preview route and state setup |
| Data Visualization | ux-ui-team data-viz lens and ui-ratchet laws and standards | Approved metric definitions, read-only aggregate data or representative fixtures |
| Platform Assurance | Stack-specific skill after detecting the stack, e.g. workers-best-practices or supabase-postgres-best-practices | Schema, fixtures, scoped staging access only when required by the check |

In each assignment pass only the changing values it consumes. For example, the Host gives the 5D Lead TARGET_REVISION, TARGET_SURFACE, PREVIEW_URL, and EVIDENCE_DIR. Give the Blind Reviewer only the prepared Stage A input for its first pass. Model and permission requirements belong in the execution configuration. A text field naming a model or write permission cannot provision either.

## Check the wiring

1. Ask Domain & Evidence to retrieve one established BNG term. Expect a BNG-scoped permalink, definition, scope, and supporting source, or an explicit gap. Run the same question from the member that consumes the term.
2. Give 4D Remediation a read-only baseline task. Expect the resolved skill revision, target, instrument, and measured output, or the exact missing execution capability.
3. Give the two Studio gates the same existing evidence packet in fresh contexts. Expect separate craft and usability verdicts tied to the same revision. A missing image or metric remains an open check.
