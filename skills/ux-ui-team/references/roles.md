# Roles and handoffs

Default: Argon design/implementation lead, fresh native UX/UI QA, host orchestrator.
Use stable responsibilities, not persistent agent identities. Add specialists only for the
brief's needs; do not fill every seat or duplicate reviews. One writer integrates each shared
surface. QA independently inspects the artifact and reports unsuppressed findings; the
implementer cannot supply independent signoff. The same fresh reviewer may cover required
code review through blind Stage A then informed Stage B under bounded QA.

| Role | Owns → handoff |
|---|---|
| Host | Scope, staffing, access, tools, acceptance → reconciled evidence and final visual confirmation |
| Argon lead | Direction, implementation decisions, repairs → implementation brief and QA-ready artifact |
| UX/UI QA | Hierarchy, grouping, spacing, readability, contrast, responsiveness, navigation, source placement → location, defect, user impact, check and fresh renders |
| Brand/visual | Composition, type, palette, authentic assets, visual language → tokens, layout, imagery and direction |
| Interaction | IA, journeys, forms, navigation, transitions, responsive priority → flows and applicable loading/empty/error/success/disabled/validation states |
| Frontend | Existing-stack implementation, semantics, performance, maintainability → source, functional proof, 4D and review inputs |
| Data visualization | Chart choice, scales, units, denominators, legends, uncertainty and accessible encoding → sourced data-to-mark specification and editable chart |
| Business | Audience, positioning, claim verification → supported recommendations and evidence gaps |
| Copy | Narrative, labels, calls to action, source labels → concise wording preserving facts and caveats |

For presentations, brand normally writes native artifacts; engineering applies to authoring/
export code or interactive deliverables. Data visualization is conditional on quantitative/
structured content. Business and copy remain distinct lenses when claims or persuasion matter.

The host resolves preferences against the brief; reproducible functional, evidence,
accessibility and code defects remain gates. Design agreement is not source comprehension.
Reuse structure and craft, never another client's identity, assets, data or decorative motifs.
Glass/gradients must retain contrast and print/export clarity. Analytical graphics retain data,
units and uncertainty; decorative curves imply no measured trend. Do not invent a parabolic
curve that implies unsupported measurements.

Prefer authentic assets and editable charts. For justified imagery specify dimensions,
transparency, layering, crop, brand constraints and decorative/data-bearing status; use
appropriate image tools. Generated visuals never establish business facts.
