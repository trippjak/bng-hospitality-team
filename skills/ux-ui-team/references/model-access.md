# Model access

Default lead: Argon. Independent UX/UI QA uses a fresh native agent with the user's configured model; a different model is optional, not a prerequisite for independence. The host orchestrator retains evidence and performs final visual confirmation. Preserve explicit user model requests. Do not install an agent platform merely to dispatch roles.

The prior Cartons trial recorded Argon as `google/gemini-4-argon-high` through an Antigravity host orchestrator. That historical receipt does not establish a current Codex model option, Gemini CLI alias, API endpoint, or callable bridge. Discover a supported CLI/API/connector route and its documented model selection locally; do not invent a command or use desktop/personal-browser control. A `gemini` executable alone does not prove Argon access. If no verified route exists, mark the lead BLOCKED, state what access is missing, and limit work to independent preparation until access or an explicit lead substitution is resolved.

Hugging Face models belong only to a separately authorized experimental run. They are not the default team's fallback, sketchpad or implementation stage. Optional Claude/Grok or other providers require a concrete role, verified access and applicable data authorization.

Record each seat's provider, exact model ID/version when exposed, supported reasoning/sampling settings, execution host, access route, permitted tools, data scope, timeout and cost limit. Record unavailable settings as unavailable. Disclose moving aliases; never claim an immutable snapshot when the provider exposes only an alias.

Distinguish: (1) CLI/tool installed, (2) authenticated route, (3) exact model listed, (4) harmless synthetic inference succeeds with required text/image modality, (5) approved for the run's scoped inputs. Only the last state permits task input. Installed CLIs and model lists are not inference proof. Use status-only commands and metadata; never print credentials or call credential-export commands. A missing model blocks that seat/arm; substitution requires an explicit plan revision before rerunning both sides where fairness is affected.

Use existing approved routes. New paid calls/hosting and client material sent to an additional provider require specific authorization unless already covered. A desire for model variance is not that authorization. Pass minimal scoped source/reference packs, not full conversation history or unrelated repos. Credentials remain in their owning provider/connector.

UI2Code_N is documented as image-text input; UIGEN-X-32B-0727 as text input. Recheck chosen endpoints. A text-only model needs an explicit reference-description step, recorded as part of that arm. Do not claim equal raw screenshot access. Model cards establish documented capabilities, not account access or useful output.

Retain safe invocation metadata, input hashes, response/artifact paths, duration, errors, repair status, and usage/cost when reported. Unknown cost is unknown. Never silently fall back, hide failed attempts, or show a generator the competing implementation.
