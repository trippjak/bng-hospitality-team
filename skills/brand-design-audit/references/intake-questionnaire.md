# Design Intake Questionnaire

The standard intake for a pre-build design audit. **Most of this the design team derives from the assets themselves** — the user only needs to answer the **bolded judgment questions** assets can't reveal. Default to confirm-from-assets.

## A · Assets (collect)
- Logo files — formats (SVG ideal; PNG/AI/EPS), and which variants exist (horizontal / stacked / icon-only / monochrome, light + dark).
- Product / concept graphics; any mood or reference imagery.
- Prior collateral (packaging, social, an old site).
- **Brand fonts you own/license — or is type open for a recommended pairing?**

## B · Color *(team extracts hexes from the logo; user confirms direction)*
- **Where on the literal↔abstract spectrum should the palette sit?** (e.g., for a patriotic brand: literal red/white/blue ↔ muted/tactical ↔ premium/heritage)
- **Any mandatory or off-limits colors?**

## C · Direction / mood *(judgment — assets can't tell us)*
- **3–5 adjectives for how it should feel.**
- **Brands/sites to evoke — and any to avoid resembling.**

## D · Imagery
- Real product photography + lifestyle shots, or only mockups for now? *(shapes how image-forward the layout can be at launch)*

## E · Asset pipeline (R2)
- **Exact R2 bucket/prefix name** (confirm spelling — a wrong path breaks every asset).
- Split: brand/marketing assets → R2 (we own); product images → the commerce CDN (e.g. Shopify) once wired. Confirm.

## F · Scope / templates
- Confirm we are **not** building a full design system — just tokens + direction + page-rhythm the build consumes.
- Which templates to design first (home · collection · product/PDP · cart · content).

## Claims to verify at intake (feed the integrity check)
Capture the *truth* behind any claim in the mockups so Phase 4 can flag false ones:
- **Ownership** — is it actually veteran/woman/minority-owned, or family-founded / supports-a-cause? (Get the precise, true framing.)
- **Origin** — is it actually made in the USA, or print-on-demand / imported? ("American Made" ≠ POD.)
- **Giving** — is there a real giving program, and what are the real numbers?
- **SLAs** — are "ships in 24h" / "free returns" actually committed?
- **Social proof** — are there real reviews/ratings yet, or is the brand pre-launch?
