# Risk Flags — trademark routing + unverified-claims checklist

Two reference batteries: §1 routes the trademark pre-check; §2 is the claims-integrity check. Both are **flagging aids, not authoritative rulings** — escalate when unsure.

---

## §1 — Trademark pre-check (routing)

### Name-type classification
- **LOW** — coined word, abstract mark, or acronym with no spelled-out risky expansion on any surface (e.g. a 3–5 letter made-up mark). Quick screen only.
- **MEDIUM** — a real dictionary word or common phrase used as the brand. Quick screen + a light same-name look; escalate if a same-category user appears.
- **HIGH → deep scan** — the name contains a high-risk token (below), reads as a near-famous mark, or a quick search surfaces an existing same-name brand/org/enforcement record.

### High-risk tokens (presence → escalate to a deep clearance scan)
- **Government / official:** national, federal, official, united states, US, USA, America/American (as the core noun), state names, agency-adjacent terms.
- **Protected communities / charity-adjacent:** veteran(s), wounded, disabled, first responder, survivor — *especially* combined with the above (these collide with congressionally-chartered orgs and charitable-solicitation law, and invite "are proceeds going to the cause?" scrutiny).
- **Regulated / certified:** organic, FDA, certified, doctor, MD, bank, insured.
- **Near-famous collisions:** anything one edit away from a household brand in the same category.

### The if/then
```
greenfield?
  ├─ name-type LOW + clean quick screen → note "clear on quick screen", proceed
  ├─ name-type MEDIUM/HIGH, OR a token hit, OR a same-name signal → DEEP SCAN (legal-advisor, web/USPTO)
  └─ deep scan → verdict HIGH/MED/LOW + clearable alternatives
brownfield (existing brand already in market) → skip (optional one-line confirm)
```

### What a deep scan covers
USPTO marks (Nice class 25 apparel / 35 retail, as relevant), confusingly-similar marks, organization/nonprofit conflicts (incl. congressional charters), state business-name + charitable-solicitation restrictions, FTC/enforcement history under the exact name, domain availability, consumer-deception/affiliation risk → **verdict + alternatives + "consult a trademark attorney before filing/domain."**

### Mitigation pattern
If a risky name is wanted anyway, a **coined mark / acronym** that never spells out the risky expansion on any surface substantially reduces (does not eliminate) the risk. The acronym itself still merits its own quick check.

## §2 — Unverified-claims checklist (integrity)

Flag any of these in mockups/copy unless backed by proof. For each: the rule + an accurate alternative.

| Claim type | Watch for | Rule / accurate alternative |
|---|---|---|
| **Ownership** | "veteran owned", "woman owned", "minority owned", "founder-led" | Only if literally true. If a family with veterans (not veteran-owned): "family founded", "a military family", "supports veteran causes". |
| **Origin** | "Made in USA", "American Made", "domestic" | POD/imported ≠ US-made (FTC Made-in-USA standard). Use "American Rooted" (ethos/inspiration) or omit. |
| **Giving** | "X% of profits to charity", "we donate" | Only with a real, stated commitment + numbers. Don't invent a percentage or beneficiary. |
| **Performance / SLA** | "ships in 24h", "free returns", "99% accuracy", "guaranteed" | Only if actually committed/operational. Omit until confirmed (often a later commerce phase). |
| **Social proof** | star ratings, "(128 reviews)", "best seller", "#1" | Pre-launch has no reviews/sales. Omit ratings until real; wire them honestly once they exist. No fabricated counts. |
| **Certifications** | "certified", "lab tested", trust badges | Only with the real cert. Don't display unearned badges. |
| **Superlatives** | "the best", "world-class", "revolutionary" | Substantiate or soften. Specific > superlative. |

> The goal isn't to strip personality — it's to make sure every *factual* claim is true. A false claim from a brand whose whole value is authenticity (veteran, wellness, etc.) is the exact reputational landmine it can't afford.
